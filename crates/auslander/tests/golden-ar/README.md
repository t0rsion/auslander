# Golden AR-quiver renderings

Determinism canaries generated by auslander itself. They are not
independent truth. Correctness of the mathematics comes from the
hand-derived AR quivers pinned in `src/arquiver.rs` and
`tests/acceptance_ar.rs`. Their only job is byte identity:
`tests/determinism_ar.rs` rebuilds each algebra, renders its AR quiver in
the normalized format, and asserts that the bytes equal the committed
file exactly, so any platform, toolchain, or code change that drifts the
vertex order, arrow order, or valuations fails the suite.

The normalized format is one line per vertex
`v<id> dim=<dim_vector> res=<residue_degree> proj=<bool> inj=<bool>`
with the dimension vector comma-joined, then one line per arrow
`a<source>-><target> base=<n> src=<n> tgt=<n>`, in stored order, with LF
line endings. `.gitattributes` marks the files `-text` so git never
rewrites their bytes.

| file | algebra | field | pinned content |
| --- | --- | --- | --- |
| `truncated-poly-3-f2.txt` | `k[x]/(x^3)` | F_2 | 3 uniserial vertices, the 4-arrow chain quiver |
| `linear-a3-f5.txt` | linearly oriented A_3, zero ideal | F_5 | 6 interval vertices, the 6-arrow zigzag |

Regeneration requires a deliberate rendering or ordering change, recorded
in the CHANGELOG:
`GOLDEN_AR_WRITE=1 cargo test -p auslander --test determinism_ar`.
