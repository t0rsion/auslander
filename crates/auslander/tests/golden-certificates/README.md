# Golden certificates

Determinism canaries generated by auslander itself. They are NOT
independent truth: correctness of the mathematics comes from the QPA
oracle (`../qpa-oracle/`), not from these files. Their only job is byte
identity: `tests/golden_cert.rs` rebuilds each presentation and asserts
that `to_canonical_json()` reproduces the committed bytes exactly, so any
platform, toolchain, or code change that drifts the certificate bytes
fails the suite on every OS the release preflight covers.

The files carry no trailing newline, and `.gitattributes` marks them
`-text` so git never rewrites their bytes.

| file | oracle family | field | presentation | purpose |
| --- | --- | --- | --- | --- |
| `truncated-poly-3-f5.json` | `truncated-poly-3` | F_5 | one loop `x`, relation `xxx` (`k[x]/(x^3)`) | the minimal monomial case: empty-trace self-overlaps |
| `commutative-square-f5.json` | `commutative-square` | F_5 | square quiver, relation `ab - cd` | a two-term relation with monic rescaling and no ambiguities |
| `preprojective-a3-f2.json` | `preprojective-a3` | F_2 | double quiver of A_3, relations `a·abar`, `abar·a - b·bbar`, `bbar·b` | productive completion: two elements join the basis |
| `self-overlap-f2.json` | `self-overlap` | F_2 | one vertex, loops `x`, `y`, relations `xx - yy`, `xy`, `yx` | a self-overlap of the leading word `yy` and a productive reduction to `xxx` |

Presentations follow `../qpa-oracle/README.md`. Regeneration requires a
deliberate certificate format change, recorded in the CHANGELOG:
`GOLDEN_CERT_WRITE=1 cargo test -p auslander --test golden_cert`.
